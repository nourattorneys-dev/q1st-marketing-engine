=== Q1st Connector ===
Lets the Quantum1st marketing engine publish approved articles to this site.

Install: Plugins → Add New → Upload Plugin → choose q1st-connector.zip → Install → Activate.
It needs a user with the Editor role and an application password for that user (Users → the user → Application Passwords).

What it does:
* Signs the engine in on hosts that remove the standard login header.
* Lets the engine write the Yoast SEO title, meta description and focus keyphrase of the posts it publishes.
* Reports the plugin, WordPress, Yoast and TranslatePress versions to the engine's connection test.

Removing it: deactivate and delete it. Posts already published stay as they are.
